How File Encryption Works

  1. User uploads a file through the form
  2. EncryptedFileStorage._save() encrypts the file with AES-256-GCM
  3. The encrypted file is stored on disk with a header containing the key ID and nonce
  4. When downloaded, EncryptedFileStorage._open() decrypts the file transparently
  5. The user receives the original, unencrypted file
