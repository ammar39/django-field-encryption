Features Demonstrated

  • EncryptedCharField - Encrypts short text like SSNs, credit card numbers
  • EncryptedTextField - Encrypts longer text content like notes
  • EncryptedJSONField - Encrypts JSON data with automatic serialization
  • BlindIndexField - Enables searchable queries on encrypted email via hash
  • EncryptedFileStorage - Encrypts uploaded files at rest using AES-256-GCM
  • Key Rotation - Seamlessly rotate encryption keys without data migration
  • Django Admin Integration - EncryptedFieldAdminMixin masks encrypted fields in list views and excludes them from search; EncryptedSearchMixin enables search via blind index
  • encrypt_field command - Encrypt/decrypt field values from the CLI with --dry-run and --batch-size support
