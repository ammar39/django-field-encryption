How Key Rotation Works

  1. Configure multiple keys in DATA_PROTECTION_KEYS
  2. Set DATA_PROTECTION_ACTIVE_KEY_ID to the new key
  3. New data is automatically encrypted with the active key
  4. Old data remains readable because old keys are still available
  5. Call FieldEncryptor.rotate_value() to re-encrypt old data with the new key
  6. Once all data is rotated, you can safely remove the old key
